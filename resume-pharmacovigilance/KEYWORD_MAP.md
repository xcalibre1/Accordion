## Tailoring per posting (do this every time — 10 minutes)

The master resume is deliberately broad. For each application, mirror that posting's exact wording:

1. **Copy the job title into the headline.** If the posting says "Drug Safety Associate I", the
   headline should read `Drug Safety Associate | ICSR Case Processing | MedDRA Coding`. If it says
   "Pharmacovigilance Specialist", use that. ATS title matching is literal.
2. **Move the posting's top three tools to the front of the Safety Databases line.** If the JD is
   Argus-heavy, `Oracle Argus Safety (foundational training)` goes first, before VigiFlow.
3. **Match the case-type emphasis:**
   - *Literature screening role* (Clarivate-type): promote the literature bullet to the top of the PV
     section and add "biomedical literature review", "safety alerts", "audit-ready documentation".
   - *Case processing role* (IQVIA/Accenture-type): keep the current order — intake → triage → entry
     → coding → narrative → QC.
   - *Aggregate reporting role*: promote PSUR/PBRER/DSUR and line listings out of Core Skills into
     their own PV bullet.
   - *Clinical trial safety / SAE reporting role*: emphasise SUSAR, 7-day/15-day expedited reporting,
     ICH-GCP, protocol and reference safety information.
4. **Copy the JD's own phrase for the same idea.** If the JD says "case processing" do not write
   "case handling"; if it says "medical coding" do not write only "MedDRA coding" — include both.
5. **Keep the file name role-specific:** `Aparna_Mishra_Drug_Safety_Associate_Resume.pdf`.
6. **Do not delete the honesty labels** ("foundational training", "certification practicum"). Change
   emphasis and ordering, never the factual level of experience.
